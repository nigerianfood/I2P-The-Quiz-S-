## Methodology

**SPM (Saves Per Million)** = Radio Playlist Saves ÷ Seed Track Streams × 1,000,000

For each track: title-only radio search (no artist name), seed verification via the `image_uri` path (`/radio/track/{trackID}/en`), save count from the radio playlist's Spotify page, stream count from the track's Spotify page.

**Methodology notes:**
- This is a fresh-release editorial playlist, so many radios are days old: several show single-digit saves and some don't display a save count at all (rendered as 0). Ratios on micro bases (under ~500K streams) are directional, not conclusive.
- Even Spotify's own live-session recording (Fcukers' L.U.C.K.Y RADAR version) has an auto-generated radio — seeds exist for essentially everything, but the engagement data trails release by weeks.
- 5 no-seed tracks all failed on common-title conflicts (Please Don't Go, Real Life, Fallin', True Love) or version mismatch (Never Seen You Dance DJ-Kicks Version).

**Scale context:** Indie dance sits between the underground (BLOND:ISH) and the club charts (Beatport) — stream bases from 10K to 64M. The clean signals are the tracks with 100+ saves; below that, read direction not magnitude.

## Key Findings

**Magnetic (The Bausa) is the playlist's clear anchor: SPM 129 with genuine scale.** 8,309 saves on 64.5M streams — the only track in the set with both a large base and an elevated ratio. The Bausa also lands a second scored entry (Lose Myself, SPM 43), making them the strongest artist in the set.

**Bonobo's Me and You (SPM 120) is the sharpest early-cycle signal.** 155 saves on just 1.3M streams for a fresh release from an established artist — his listeners actively seed radios as soon as new material drops. Barry Can't Swim shows the same pattern: Return To Bhibo at SPM 112 with 311 saves on 2.8M streams.

**The Wave (Jungle) provides the mid-table benchmark: SPM 83 on 10M streams with 836 saves.** Jungle's crossover base behaves more like a mainstream act — bigger absolute numbers, more diluted ratio.

**The freshness gradient is visible across the whole set.** Nine tracks have verified radio seeds but incomplete data (no stream count surfaced, or radios with 0–16 saves) — these are releases days-to-weeks old where the radio exists before the engagement does. Two radios (Scaredy Cat, Mark Me Up) don't even display a save count yet, and Falling Again's radio has literally 0 saves against 168K streams. This playlist is a snapshot of the discovery machine mid-spin-up; re-measuring in 2–4 weeks would produce a very different table.

**Even Spotify's own live-session content gets radios.** The Fcukers RADAR live recording has its own verified radio (2 saves) — confirmation that radio generation is fully automatic and version-specific.

**The 5 unscored tracks are all title/version conflicts** — Please Don't Go (KC & The Sunshine Band's canon owns the title), Real Life, Fallin' (Alicia Keys), True Love, and the TEED DJ-Kicks version mismatch. Consistent with every prior analysis: generic titles and alternate versions are the two structural blind spots of title-only search.
